Introdução ao HTML

HTML (HyperText Markup Language) é a linguagem de marcação usada para estruturar páginas web. Ele usa "tags" para definir diferentes tipos de conteúdo.

Neste trabalho, vamos explorar os principais elementos do HTML que ajudam a construir uma página web.

Listas em HTML

HTML oferece duas formas principais de listas:

Lista não ordenada (com marcadores)

  • Item 1
  • Item 2
  • Item 3

Lista ordenada (numerada)

  1. Primeiro item
  2. Segundo item
  3. Terceiro item
